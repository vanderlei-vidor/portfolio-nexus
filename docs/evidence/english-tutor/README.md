# English Tutor Evidence

Este diretório reúne a camada de evidência do case English Tutor / AI Polyglot Tutor.

O objetivo é preservar a força da narrativa sem prometer precisão pedagógica absoluta, ausência de alucinação ou privacidade total. O case pode falar de arquitetura híbrida, Teacher Brain determinístico, memória estruturada, CEFR, prática por cenários e LLM local quando configurado dessa forma. Claims de correção perfeita, privacidade absoluta ou execução sempre local dependem de testes, configuração e matriz de dados anexada.

## Claims Públicos Permitidos

- Tutor de idiomas com arquitetura híbrida entre regras pedagógicas, memória e geração textual.
- Teacher Brain tratado como camada determinística para orientar decisões pedagógicas antes da resposta do LLM.
- Progresso, vocabulário, erros recorrentes, cenários e CEFR apresentados como contexto de aprendizado.
- LLM local mencionado apenas quando configurado dessa forma.
- A arquitetura reduz dependência do LLM para decisões pedagógicas, sem afirmar que elimina erro ou alucinação.
- O case do portfolio teve seções abaixo da dobra adiadas para melhorar a entrada inicial da página.

## Claims Ainda Não Permitidos

- Zero alucinações gramaticais.
- Correção pedagógica perfeita.
- Privacidade absoluta.
- Execução sempre local em qualquer instalação.
- Nenhum dado enviado ao modelo sem matriz real de fluxo de dados.
- Suporte multilíngue irrestrito sem matriz real de idiomas implementados.
- Teacher Brain validado sem testes pedagógicos anexados.
